# ปุ่ม "อนุญาตเสมอ" บนการ์ดอนุมัติของ StampLab

## หลักการ

1. เวลา Claude Code ขอสิทธิ์รันคำสั่ง StampLab จะเด้งการ์ดมุมขวาบน ตอนนี้มี 3 ปุ่ม: **ปฏิเสธ** / **อนุญาต** / **อนุญาตเสมอ**
2. "อนุญาตเสมอ" = อนุญาตครั้งนี้ **และ** บอก Claude Code ให้จำคำสั่งแบบนี้ไว้ ครั้งหน้าจะไม่ถามอีก — คนเขียนกฎลงไฟล์คือ Claude Code เอง StampLab แค่ส่งคำแนะนำกลับไป ไม่ได้ไปแก้ไฟล์ตั้งค่าเอง
3. กฎเป็น **ระดับเครื่อง** (ไฟล์ `~/.claude/settings.json`) กดครั้งเดียวใช้ได้ทุกโปรเจกต์ทุกแชต รวมถึงแชตที่เปิดแบบไม่เลือกโฟลเดอร์
   *เปลี่ยนเมื่อ 2 พ.ย. 2569 — ของเดิมเก็บรายโปรเจกต์ แชตที่ไม่มีโฟลเดอร์จึงเขียนกฎลงโฟลเดอร์ชั่วคราวที่ถูกลบทิ้งพร้อมแชท กฎหายทุกครั้งและต้องกดซ้ำไม่จบ*

## วิธีใช้

- รอการ์ดขึ้น → อ่านคำสั่งในกรอบสีเข้ม → ถ้าเป็นคำสั่งที่ยอมให้ทำซ้ำได้เรื่อย ๆ กดปุ่มล่างสุด **"อนุญาตเสมอ — ไม่ต้องถามอีก"**
- ใต้ชื่อปุ่มมีบรรทัดเล็ก ๆ บอกกฎที่จะถูกบันทึก เช่น `Bash(npm run test *)` — **อ่านบรรทัดนี้ก่อนกดทุกครั้ง** เพราะกฎมักกว้างกว่าคำสั่งที่เห็น เครื่องหมาย `*` แปลว่า "อะไรก็ได้ต่อท้าย"
- ถ้าการ์ดไม่มีปุ่มนี้ แปลว่าคำขอนั้นตั้งเป็นกฎไม่ได้ (เช่นการขอแก้ไฟล์ หรือกฎที่จะได้กว้างเกินไปจนครอบทั้งเครื่องมือ) ให้ใช้ **อนุญาต** ธรรมดา

## วิธีเช็กว่าทำงาน

1. หลังกด เปิดเมนู StampLab (ไอคอนบนแถบเมนูด้านบน) จะเห็นแถว **"กฎอนุญาตเสมอ"** พร้อมตัวเลขจำนวนกฎ และกฎล่าสุดใต้ชื่อแถว
2. สั่ง Claude ให้รันคำสั่งเดิมซ้ำ → **ต้องไม่มีการ์ดขึ้น และ Claude ไม่ถามในแชต** นั่นคือผ่าน
3. อยากเห็นของจริงในไฟล์ เปิด Terminal แล้วรันคำสั่งเดียวนี้:

```bash
cat ~/.claude/settings.json
```

กฎจะอยู่ในรายการ `permissions.allow`

## วิธีปิดและแก้ปัญหา

- **ลบกฎทีละข้อ** — เมนู StampLab → `การตั้งค่า…` → หัวข้อ "อนุมัติคำขอของ Claude" → กด **ลบ** ข้างกฎนั้น ลบแล้ว Claude จะกลับมาถามคำสั่งนั้นอีก (StampLab เอากฎออกจาก `~/.claude/settings.json` ให้ และเคลียร์กฎเก่าที่เคยเก็บรายโปรเจกต์ด้วย โดยไม่แตะกฎข้ออื่นหรือค่าอื่นในไฟล์)
- **กดผิด อยากถอนทันที** — ลบตามข้อบน กฎไม่มีผลย้อนหลัง คำสั่งที่รันไปแล้วก็แล้วไป
- **ปิดการ์ดทั้งหมด** — `การตั้งค่า…` → ปิดสวิตช์ "ตอบคำขอสิทธิ์ของ Claude Code จาก StampLab" แล้ว Claude จะถามในหน้าต่างแชตตามปกติ
- **ไม่เห็นการ์ดเลย** เช็ก 3 อย่างตามลำดับ
  1. StampLab เปิดอยู่ไหม (ดูไอคอนบนแถบเมนู)
  2. สวิตช์ "ตอบคำขอสิทธิ์ของ Claude Code จาก StampLab" เปิดอยู่ไหม
  3. **ออโต้ไพลอตเปิดอยู่ไหม** — ถ้าเปิดและแชตนั้นอยู่โหมด auto ออโต้ไพลอตจะตัดสินแทนทันทีโดยไม่มีการ์ด ปิดสวิตช์ออโต้ไพลอตถ้าอยากกดเอง
- **ไฟล์ที่เกี่ยวข้อง**
  - `~/.claude/settings.json` — กฎตัวจริง Claude Code เป็นคนเขียน (รายการ `permissions.allow`)
  - `<โปรเจกต์>/.claude/settings.local.json` — ที่เก็บเดิมก่อน 2 พ.ย. 2569 กฎเก่าที่ยังค้างอยู่ที่นี่ยังมีผล และถูกลบให้เมื่อกดลบกฎข้อนั้น
  - `~/Library/Application Support/StampLab/approval-rules.json` — บันทึกของ StampLab เอง ไว้ให้เมนูแสดงรายการและลบได้
