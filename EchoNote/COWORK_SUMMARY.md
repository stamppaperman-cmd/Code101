# EchoNote — สรุปงาน 2026-09-06 → 07

ถอดเสียง/สรุปภาษาไทยแบบออฟไลน์บน macOS งานรอบนี้เริ่มจากการยืนยันของค้างในหน้าส่งงานเดิม
แล้วขยายเป็นการเก็บหนี้เทคนิคทั้งหมด และทำระบบอ้างอิงแบบ NotebookLM ให้ทำงานในเครื่อง

## ยืนยันได้แล้ว

**`fillGaps` ได้ผลจริง** — ไฟล์เดิม โหมดเดิม โมเดลเดิม coverage **74.3% → 92.4%**,
ช่วงที่ไม่มีข้อความ **32 ช่วง (26%) → 4 ช่วง (110 วิ)**, segment 871 → 1,092
แลกด้วยเวลา ~56 → ~96 นาที ซึ่งยังแยกไม่ออกว่าเป็นงานจริงเท่าไร ต้อง A/B ต่อ

## แก้แล้ว

- **ตายแล้วเสียทั้งชั่วโมง** → ซอยเสียงเป็นบล็อกละ 10 นาที (ตัดที่จุดเงียบที่สุด),
  retry 1 ครั้งต่อบล็อก, เขียน segment ลงดิสก์ทุกบล็อกจบ
- **ไม่มี log** → `echonote.log` มี footprint ทุกบรรทัด flush ก่อนงานที่เคยทำแอปตาย
- **`deploy.sh` ฆ่างานที่รันอยู่** → ตรวจก่อน และตรวจเฉพาะตอนแอปเปิดอยู่จริง
- **เกลาคำทุกบรรทัด** → เฉพาะ 25% ที่ Whisper มั่นใจน้อยที่สุด (ใช้ `avgLogprob` ที่เคยทิ้ง)
- **ชื่อผู้พูดสลับกัน** → ตรวจทิศทางหลักฐาน: ถูกเรียกชื่อ = หลักฐานของคนถูกเรียก ไม่ใช่คนพูด
- **ไม่มีเทสต์เลย** → 77 เทสต์ ผ่านทั้งหมด (`xcodebuild -scheme EchoNote test`)
- **รันไฟล์ซ้ำเสียเวลาฟรี** → ตรวจ fingerprint แล้วเปิดผลเดิมให้แทน
- **ContentView 669 บรรทัด** → แยกเป็น 3 ไฟล์

## ทำใหม่

- **สรุปมีเลขอ้างอิงทุกข้อ** กดเวลาแล้วเล่นเสียงจริงตรงนั้น — จุดที่ NotebookLM ทำไม่ได้
  เพราะมันมีแค่ข้อความ วัดได้ 100% cited บนไฟล์ทดสอบ
- **`SummaryAudit` ชี้ตำแหน่งได้** และจับ "ข้อเท็จจริงจริงแต่อ้างผิดที่" ซึ่งไม่มีทางเห็นถ้าไม่มี citation
- **แท็บ "ถาม"** ตอบจากไฟล์นั้นเท่านั้น ประโยคไหนไม่มีบรรทัดอ้างอิงถูกตัดทิ้ง
  ตอบว่า "ไม่พบคำตอบในไฟล์นี้" เป็นคำตอบที่ถูกต้อง
- **ตัวเลือก Gemini (ฟรี)** ปิดไว้เป็นค่าเริ่มต้น ส่งเฉพาะ*ข้อความดิบ* ไม่ส่งสรุปและไม่ส่งไฟล์เสียง
  key เก็บใน Keychain ส่งทาง header ไม่ใช่ query string
- **คำเฉพาะ** ใส่ชื่อคน/แบรนด์ไว้ล่วงหน้า เข้าทางขั้นเกลาคำที่มีตัวกันความเสียหายอยู่แล้ว

## สิ่งที่ต้องรู้ก่อนทำต่อ

- **`nomic-embed-text` ไม่อ่านภาษาไทย** — คำถามไทย 3 คำถามที่ไม่เกี่ยวกันเลย ได้คะแนน
  เท่ากันทุกตัวเลข retrieval จึงเปลี่ยนมาใช้ character trigram ซึ่งวัดแล้วแยกได้จริง
- **อย่าเอา vocabulary ใส่ `promptTokens`** วัดแล้วสะกดถูกขึ้นแต่ตกไปทั้งประโยค
- **อย่าลบโมเดล `large-v3` ทิ้ง** ไฟล์ครบดี ไม่ใช่สาเหตุที่แอปตาย
- **อย่าใช้ `gemma4:26b`** 18 GB บนแรม 16 GB
- สาเหตุที่แอปตายกลาง transcribe ยังไม่ปิดเคส — log พร้อมเก็บหลักฐานรอบหน้าแล้ว
