Drop Shelf — ชั้นวางของรอส่ง AirDrop
==========================================

ติดตั้ง
1. ลาก "Drop Shelf" ไปใส่โฟลเดอร์ Applications (ลากไปที่ลูกศรในหน้าต่างนี้ได้เลย)
2. เปิดแอปครั้งแรก macOS จะเตือนว่าตรวจสอบผู้พัฒนาไม่ได้ (เพราะแอปนี้ทำกันเอง ไม่ได้ขึ้น App Store)
   → macOS 15 ขึ้นไป: กด "เสร็จสิ้น/Done" ไปก่อน แล้วเปิด
     System Settings > Privacy & Security เลื่อนลงล่างสุด
     กด "Open Anyway / เปิดต่อไป" ตรงชื่อ Drop Shelf แล้วใส่รหัสเครื่อง
   → macOS 14: คลิกขวาที่ไอคอนแอป เลือก "Open / เปิด" แล้วกด "Open" ย้ำอีกครั้ง
   ทำครั้งเดียว ครั้งต่อไปเปิดได้ปกติ
3. เปิดได้แล้ว จะเห็นไอคอนถาดลูกศรขึ้นที่แถบเมนูด้านบนขวา และชั้นวางเด้งขึ้นมาใต้แถบเมนู
   (แอปไม่มีไอคอนใน Dock — อยู่ที่แถบเมนูอย่างเดียว)

ใช้งาน
- คลิกซ้ายที่ไอคอนแถบเมนู = เปิด/ปิดชั้นวาง
- คลิกขวาที่ไอคอน = เมนู (ตั้งค่า / ออกจากแอป)
- คีย์ลัด Control + Option + Command + D = เปิด/ปิดชั้นวาง
- ลากไฟล์ รูป หรือลิงก์ มาวางบนไอคอนแถบเมนู หรือบนชั้นวาง
- กำลังลากไฟล์อยู่ แล้วเขย่าเมาส์ซ้ายขวา ชั้นวางจะเด้งมาหา
- พิมพ์ข้อความหรือวางลิงก์ในช่องพิมพ์ แล้วกด Enter = ได้การ์ดข้อความ
- Command + V วางรูปที่แคปหน้าจอได้
- กดปุ่ม "ส่งผ่าน AirDrop" = ส่งทุกอย่างบนชั้นวางทีเดียว
- Esc = ปิดชั้นวาง

อยากให้เปิดเองทุกครั้งที่เปิดเครื่อง
System Settings > General > Login Items & Extensions > กด + แล้วเลือก Drop Shelf

ต้องการ macOS 14 (Sonoma) ขึ้นไป ใช้ได้ทั้ง Mac ชิป M และ Intel
แอปไม่ส่งข้อมูลออกนอกเครื่อง ไม่ต้องใช้อินเทอร์เน็ต
