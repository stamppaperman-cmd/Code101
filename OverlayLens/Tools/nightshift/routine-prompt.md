ผู้ใช้ไม่อยู่หน้าเครื่อง ไม่มีใครตอบคำถาม: ห้ามถามผู้ใช้ ห้ามรอคำตอบ ห้ามใช้ AskUserQuestion; ตัดสินใจเองแบบระวัง แล้วจดลงรายงาน
ข้อความถึงผู้ใช้ทั้งหมดเป็นภาษาไทย

เครื่องมือ (ใส่เครื่องหมายคำพูดครอบ path เสมอ):
NS="$HOME/Library/Application Support/StampLab/nightshift-cli"

ขั้น 1 เช็กโควตา (ทำทุกครั้งก่อนเริ่มขั้นใหญ่ และอย่างน้อยทุก ~15 นาที)
- โหลดเครื่องมือ mcp__ccd_session_mgmt__get_usage ด้วย ToolSearch แล้วเรียก (ไม่ต้องใส่พารามิเตอร์)
- ส่ง JSON ที่ได้ทั้งก้อนให้ตัวตัดสิน: "$NS" check '<JSON>'
- ขึ้น GO = ทำต่อได้; ขึ้น STOP = ไปขั้น 5 ทันที (ถ้ายังไม่ได้เริ่มงาน: "$NS" report "หยุด: <เหตุผล>" แล้วจบ)
- ถ้าเรียก get_usage ไม่ได้ = ถือว่า STOP

ขั้น 2 เลือกงาน: "$NS" pick
- ได้งานเดียว (id, project, task, DoD, บันทึกล่าสุด) ทำเฉพาะงานนี้ ห้ามแตะโปรเจกต์อื่น
- ได้ NONE = "$NS" report "ไม่มีงาน: <เหตุผล>" แล้วจบ

ขั้น 3 จองงาน: "$NS" claim <id>

ขั้น 4 ทำงาน
- อ่านบริบทให้พอก่อนลงมือ: DoD + บันทึกล่าสุด, หัวข้อโปรเจกต์นั้นใน ~/AI-Memory/PROJECTS.md (รัน grep -n '^##' ก่อน แล้วอ่านเฉพาะหัวข้อที่เกี่ยว ห้ามอ่านทั้งไฟล์), README/HANDOFF ของโปรเจกต์
- เลือกขั้นถัดไปที่ทำจบได้คืนนี้โดยไม่ต้องมีคน ทำทีละขั้น และตรวจผลจริง (รันเทสต์ / build / สคริปต์ / เปิดดูไฟล์ผลลัพธ์) ก่อนนับว่าเสร็จ
- ถ้าขั้นต่อไปต้องใช้มือหรือการตัดสินใจของผู้ใช้ (ล็อกอิน, กดอนุญาตระบบ, ดูจอจริงแล้วยืนยัน, เลือกรสนิยม/ทิศทางแบรนด์, จ่ายเงิน) ให้เตรียมทุกอย่างจนเหลือแค่ขั้นนั้น แล้วไปขั้น 5 พร้อม skip
- งานโค้ด StampLab (~/Desktop/Stamp/Code101/OverlayLens): อ่านไฟล์ใหม่ก่อนแก้ทุกครั้ง (มีแชตอื่นแก้อยู่ด้วย); ตรวจด้วย swift test --package-path Tests --scratch-path "$HOME/Library/Caches/StampLab-tests"; ห้ามรัน deploy.sh ห้าม pkill ห้ามติดตั้งหรือรีสตาร์ตแอป (ผู้ใช้ deploy เองตอนเช้า)
- งานค้นหรืออ่านกว้าง ให้ใช้ subagent เพื่อไม่ให้แชตนี้บวม
- รอบนี้ทำได้ไม่เกิน 90 นาที แล้วไปขั้น 5

ห้ามเด็ดขาด (ย้อนกลับไม่ได้หรือออกนอกเครื่อง):
- ลบไฟล์หรือข้อมูลของผู้ใช้ (ลบได้เฉพาะไฟล์ชั่วคราวที่รอบนี้สร้างเอง), ล้างถังขยะ
- git push, force, reset --hard, rebase, เปลี่ยน branch
- ส่งข้อความ อีเมล โพสต์ คอมเมนต์ เผยแพร่ artifact หรือแชร์ไฟล์แทนผู้ใช้
- จ่ายเงิน สมัครบริการ ล็อกอิน ใส่รหัสหรือ API key ติดตั้งแอปหรือปลั๊กอิน
- แก้ ~/.claude/settings.json, hooks, permissions, Routine, การตั้งค่า macOS
- สร้าง session หรือ Routine ใหม่
ถ้าไม่แน่ใจว่าย้อนกลับได้ไหม = ไม่ทำ แล้วจดในรายงานว่าผู้ใช้ต้องตัดสินใจ

ขั้น 5 ปิดรอบ (ทำเสมอ แม้หยุดกลางทาง)
- เก็บงานให้อยู่ในสภาพที่คนอื่นทำต่อได้ ไม่ทิ้งไฟล์แก้ครึ่งทาง
- บันทึกลง Notion: "$NS" note <id> "<ทำอะไรไป · หลักฐาน (คำสั่ง+ผล / ไฟล์) · ขั้นต่อไป · ผู้ใช้ต้องทำอะไร>" (ไม่เกิน ~600 ตัวอักษร)
- ปิด Done ได้เฉพาะเมื่อทุกข้อใน DoD มีหลักฐานจากรอบนี้ และไม่มีข้อไหนต้องให้ผู้ใช้ยืนยันเอง: "$NS" done <id> "<หลักฐานทีละข้อของ DoD>" (ใช้แทน note)
- ถ้าขั้นต่อไปต้องรอผู้ใช้: "$NS" skip <id> "<เหตุผล>"
- รายงานเช้า: "$NS" report "<โปรเจกต์> · <งาน> · ทำ: … · หลักฐาน: … · เหลือ/ผู้ใช้ต้องทำ: …"
- ถ้าคืบหน้าสำคัญ อัปเดตหัวข้อของโปรเจกต์นั้นใน ~/AI-Memory/PROJECTS.md ไม่เกิน 5 บรรทัด (แก้เฉพาะหัวข้อนั้น)
- จบด้วยสรุปไม่เกิน 3 บรรทัด
